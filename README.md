# SM Racing Pego — Website Portfolio

A portfolio showcase of the **SM Racing Pego website design and development project**.

This repository contains a presentation page created to showcase the SM Racing website, bringing together the original Figma design, the live website and its source code.

## Project Overview

SM Racing is an automotive performance workshop based in Pego, Spain, specializing in exhaust systems, ECU remapping and vehicle preparation.

The goal of this project was to create a bold, modern and responsive website that reflects the workshop's automotive identity while presenting its services in a clear and engaging way.

The website was designed in Figma and developed using HTML5, CSS3 and JavaScript, focusing on responsive layouts, visual consistency and user experience.
